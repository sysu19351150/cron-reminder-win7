# Win7 轻量化定时提醒器

专为 Windows 7 系统打造的**零重型依赖**定时提醒工具：后台静默运行，通过本地网页图形化配置定时规则，到点用系统右下方原生气泡提醒你。

## 功能特性

- 后台 Node.js 服务常驻运行
- **全图形化定时配置**：秒 / 分 / 时 / 日 / 月 / 周 六个维度下拉选择，无需手写 cron 表达式
- **5 个常用模板**一键填充（每 30 分钟、每小时整点、每天 9:00、工作日 18:00、每周一 9:30）
- **最近 5 次触发时间**实时预览
- 日期 / 星期**智能互斥**，避免配置出语义冲突的规则
- 原生系统右下角气泡通知
- 数据全量本地 JSON 持久化（原子写入，断电不损坏）
- 支持秒级精度 cron 调度

## 快速开始

```bash
npm install
npm start
```

启动后在浏览器访问 <http://localhost:28765> 即可配置提醒。

## 生成测试数据（可选）

```bash
node test-init.js
```

会写入 3 条测试提醒（会覆盖当前提醒数据）。

## 打包为单文件 exe

```bash
npm run build
```

产物输出到 `dist/reminder-server.exe`（基于 Node 16、原生兼容 Windows 7）。
